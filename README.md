Web-Based Login Interface

**Project type:** Individual project  
**Technologies:** HTML5, CSS3, JavaScript  
**Purpose:** Demonstrate the design and implementation of a responsive login interface with basic client-side form validation.

## Features

- Responsive layout for desktop and mobile screens
- Email and password input fields
- Show/hide password control
- Client-side validation for required fields, email format, and minimum password length
- Accessible labels and feedback messages
- No external backend or account authentication

## Project files

- `index.html` — page structure and form elements
- `style.css` — layout, colours, typography, and responsive styles
- `script.js` — password visibility control and form validation

## How to run

1. Download or clone the repository.
2. Open `index.html` in a web browser, or open the project folder in Visual Studio Code.
3. For a convenient development workflow, use the Live Server extension in VS Code if installed.

## Important scope note

This project is a **front-end demonstration**, not a complete authentication system. It does not connect to a server, verify real user accounts, or save submitted credentials. The success message only indicates that the form passed local browser-side validation.

## Hosting

You can publish this static project with GitHub Pages. In the repository, open **Settings → Pages**, select the main branch and root folder, and save. GitHub will provide the published site address after deployment.
